## 1. 双工作面原则
M07 给业务管理者完整的业务池、规则、统计、审批、专业审核；M10 为所有员工默认提供**未来待办 / 过去报告 / 我的智能体**三入口。根据任职与权限“组合”，不是按 HRM 角色硬编码切菜单。[B/D/P]

## 3. M10 页面规格
| ID | 页面 | 核心布局 | 行动 |
|---|---|---|---|
| M10-UI01 | 我的首页 | 上：当日优先待办；中：历史报告；下：个人智能体 | 处理/提问 |
| M10-UI02 | 我的待办 | 任务来源、对象、截止、优先级、允许操作 | 跳专业表单或受控 Action |
| M10-UI03 | 我的申请 | 受控动态表单、附件、进度时间线 | 草稿/提交/撤回 |
| M10-UI04 | 我的报告 | 本人 ResultRef、EvidenceRef、确认状态 | 查看证据/补充说明 |
| M10-UI05 | 我的智能体 | Personal Agent + 专业工具列表、来源与确认 | 获建议/确认低风险操作 |
| M10-UI06 | 个人设置 | 授权岗位引用、设备通知、语言、隐私 | 查看/授权申请 |

## 4. 前端交互验收
- PC 主操作 3 次点击内进入任务；手机 360px 不横向溢出，核心操作按钮易于触达。[P]
- 页面内不得暴露完整工资、证件号；危险操作需明确确认和理由，审批人不能由客户端替换。[B/P]
- 加载骨架、空态、离线、重试、403、409、422、超时均有明确反馈。[P]
- `role_template_ref` 是服务端下发的可见能力投影；前端隐藏不是授权措施。[B/P]
- 通用组件在 POMS 核心中，灯具/定时器差异作为行业能力包（表单 schema、字段、专业 Skills、业务流程引用）；更换专用包不修改权限内核。[P]
