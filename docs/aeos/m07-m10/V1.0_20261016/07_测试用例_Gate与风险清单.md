## 3. 已知 HLC 事实与不可外推之处
HLC 仓库可读取关键代码；`routes/tasks.py` 是内存上传进度队列；`routes/auth.py` 包含默认初始口令常量及内存限流，存在需验证的设计隐患。不能因存在 `src/config/capabilityNavigation.ts` 中的 SSO/PWA/插件项就判定相关能力已经生产可用。[C]
